# Командная строка

[English version](../en/cli.md)

Инструмент устанавливается как `azarovo-martingale`. У каждой команды есть `--help`.

```sh
azarovo-martingale --version
```

## `interval`: интервал мониторинга

```sh
azarovo-martingale interval 512 20               # выводит 71
azarovo-martingale interval 512 20 --delta 0.05  # больший риск, более длинный интервал
azarovo-martingale interval 512 20 --n-max 60    # ограничен 60 шагами
```

Аргументы: свободный запас `R` в МБ и `c` в МБ за шаг. Вывод — интервал в базовых
шагах, `0`, если `R <= c`.

## `detect`: тревоги роста по журналу

```sh
azarovo-martingale detect log.csv --c 20                   # формулы (11), (12)
azarovo-martingale detect log.csv --c 20 --vm vm-01        # одна ВМ
azarovo-martingale detect log.csv --c 20 --detector cusum  # формула (14)
azarovo-martingale detect log.csv --c 20 --detector mixture
azarovo-martingale detect log.csv --c 20 --detector mixture --bets 0.05,0.1,0.2 --weights 1,1,2
```

Вывод — по одной строке на тревогу: `имя-ВМ<TAB>время`. Детектор проходит весь журнал с
перезапуском после каждой тревоги. `--c` обязателен: детектору нужна граница изменения за
шаг (оценить её можно командой `analyze`).

С `--detector mixture` параметр `--bets` задаёт сетку долей ставки, а `--weights` — вес
каждой ставки в смеси; оба списка через запятую. По умолчанию ставки 0,1, …, 0,9 с равными
весами. Веса нормируются до суммы 1, поэтому `1,1,2` означает `0,25,0,25,0,5`. Весов должно
быть столько же, сколько ставок. С другими детекторами эти параметры отклоняются, а
`analyze` принимает те же два параметра.

## `analyze`: полный анализ журнала

```sh
azarovo-martingale analyze log.csv --out results/run1
azarovo-martingale analyze log.csv --out results/run1 --plot   # нужно дополнение plot
azarovo-martingale analyze log.csv --json                     # JSON в стандартный вывод
azarovo-martingale analyze log.csv --reserve 512              # нет столбца free_mb
```

Команда пишет `summary.md` и `summary.json` в папку результатов (по умолчанию
`results/<имя журнала>`), печатает отчёт в Markdown, а с `--plot` записывает по
`trace_<ВМ>.png` на каждую ВМ. Параметры:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--delta` | 0,01 | допустимый риск исчерпания запаса |
| `--alpha` | 0,01 | допустимая вероятность ложной тревоги |
| `--lam` | 0,5 | доля ставки формулы (11) |
| `--n-min`, `--n-max` | 1, 600 | интервал после перераспределения и его верхняя граница, шагов |
| `--fixed` | 1,5,10 | фиксированные интервалы для сравнения, шагов через запятую |
| `--c` | оценивается | использовать это `c` для всего журнала |
| `--train-frac` | 0,5 | доля журнала для оценки `c`; 0 — весь журнал |
| `--c-quantile`, `--c-margin` | 1, 1,2 | квантиль скоростей и запас для `c` |
| `--reserve` | нет | постоянный запас в МБ, если в журнале нет `free_mb` |
| `--cusum-threshold` | 1e5 | порог формулы (14) |
| `--grace` | 60 | секунд после участка роста, которые ещё считаются обнаружением |
| `--step` | 1 | базовый шаг в секундах |
| `--split-risk` | выкл. | разделить `delta` и `alpha` поровну между ВМ |
| `--bets` | 0,1, …, 0,9 | смесь: доли ставки в `[0, 1)`, через запятую |
| `--weights` | равные | смесь: один вес на ставку, нормируется до суммы 1 |
| `--sep` | определяется | разделитель столбцов |
| `--plot` | выкл. | нарисовать график по каждой ВМ |
| `--json` | выкл. | вывести JSON вместо Markdown |

## Код возврата

`0` при успехе. `2` при ошибке в аргументах или данных; сообщение выводится в
стандартный поток ошибок.
